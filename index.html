Node.js Basics

Question 1: What is Node.js?

Answer:-Node.js is an open-source, cross-platform JavaScript runtime environment that allows developers to run JavaScript outside the browser. It is built on Google's V8 JavaScript engine and is mainly used for building fast, scalable, and efficient server-side applications.

Question 2: What is the difference between Single-threaded and Multi-threaded architecture?

Answere:- The difference between Single-threaded and Multi-threaded architecture

Single-threaded

- Uses only one thread to execute tasks.

- Executes one task at a time.

- Simpler and uses less memory.

- Node.js follows a single-threaded event-driven architecture.

Multi-threaded

- Uses multiple threads to execute tasks simultaneously.

- Executes one task at a time. Can execute multiple tasks at the same time.

- More complex and uses more system resources.

- Languages like Java and C# commonly support multi-threading.

Question 3: What is the difference between Synchronous and Asynchronous operations?

Answere:- The difference between Synchronous and Asynchronous operations:

Synchronous Operations

- Tasks are executed one after another.

- The next line of code waits until the current task is complete.

- Can slow down the application.

Asynchronous Operations

- Tasks do not wait for previous tasks to finish.

- Other code continues executing while waiting for a task to complete.

- Improves performance and responsiveness.

Question 4: What is the difference between Blocking and Non-blocking operations?

Answere:- The difference between Blocking and Non-blocking operations

Blocking

- Stops the execution of the program until the task is finished.

- Other operations must wait.

- Common in synchronous code.

Non-blocking

- Does not stop the execution of the program.

- Other operations can continue while the task is running.

- Common in asynchronous code.

Modules

Question 5: What is a Module in Node.js?

Answere:- A module is a reusable piece of code that contains functions, variables, or objects.

Question 6: What is the purpose of module.exports?

Answere:- module.exports is used to export functions, objects, or variables from a module so they can be used in other files.

Question 7: What is the purpose of require()?

Answere:- require() is used to import modules into another file. It allows us to access the exported functionality of a module.

NPM

Question 8: What is NPM?

Answere:- NPM (Node Package Manager) is the default package manager for Node.js.

Question 9: What information is stored inside the package.json file?

Answere:- The package.json file contains important information about a Node.js project, including:

      1. Project name
      2. Version
      3. Description
      4. Main entry file
      5. Scripts
      6. Author
      7. License
      8. Dependencies
      9. DevDependencies

Core Modules

Question 10: What is the purpose of the following Node.js modules?

HTTP Module

The HTTP module is used to create web servers and handle HTTP requests and responses.

URL Module

The URL module is used to parse, create, and manipulate URLs.

File System (fs) Module

The File System (fs) module is used to read, write, update, delete, and manage files and directories.

Path Module

The Path module is used to work with file and directory paths in a platform-independent way.

Events Module

The Events module allows objects to emit and listen for events. It is useful for event-driven programming in Node.js.

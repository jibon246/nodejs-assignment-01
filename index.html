Part 1: Theory Questions

V8 Engine

Question 1: What is the V8 Engine?

Ans:- V8 Engine is a JavaScript engine developed by Google that quickly converts JavaScript code into machine code and executes it.

Question 2: Why is the V8 Engine important for Node.js?

Ans:- The V8 Engine is important for Node.js because it converts JavaScript code into machine code and executes it very quickly. This allows Node.js to run JavaScript efficiently outside the browser, making it fast and suitable for building scalable server-side applications.

Question 3: What is the main responsibility of the V8 Engine?

Ans:- The main responsibility of the V8 Engine is to convert JavaScript code into machine code and execute it efficiently, enabling JavaScript programs to run quickly.

Execution

Question 4: What is the difference between Synchronous and Asynchronous execution?

Ans:- Synchronous execution runs tasks one after another. Each task must finish before the next one starts, so the program waits for each operation to complete.

Asynchronous execution allows tasks to run without blocking the execution of other code. Long-running operations (such as reading a file or making an API request) can happen in the background while the program continues executing other tasks.

Question 5: What is the Call Stack?

Ans:- The Call Stack is a data structure used by the JavaScript engine to keep track of function calls. It follows the Last In, First Out (LIFO) principle, meaning the last function added to the stack is the first one to be removed.

When a function is called, it is pushed onto the call stack. When the function finishes executing, it is popped off the stack.

Event Loop

Question 6:What is the Event Loop?

Ans:- The Event Loop is a mechanism in JavaScript that manages asynchronous operations. It continuously checks whether the Call Stack is empty. If the stack is empty, it takes pending callbacks from the Callback Queue and pushes them onto the Call Stack for execution.

Question 7: Why is the Event Loop needed in Node.js?

Ans:- The Event Loop is needed in Node.js because it allows the application to handle asynchronous operations without blocking the main thread.
The Event Loop makes Node.js fast, efficient, and capable of handling multiple requests concurrently without creating a new thread for each request.

Question 8: How does the Event Loop help execute asynchronous code?

Ans:- The Event Loop helps execute asynchronous code by monitoring the Call Stack. When the Call Stack becomes empty, it takes completed asynchronous callbacks from the Callback Queue and pushes them onto the Call Stack for execution. This allows JavaScript to continue running other code while waiting for asynchronous operations (such as setTimeout(), file reading, or API requests) to complete.

libuv

Question 9: What is libuv?

Ans:- libuv is a cross-platform C library used by Node.js to handle asynchronous I/O operations. It provides features such as the Event Loop, thread pool, file system operations, networking, and timers.

Question 10: What types of tasks are handled by libuv?

libuv handles asynchronous and non-blocking tasks in Node.js, including:

  1. File system operations (reading and writing files)
  2. Network operations (HTTP requests, TCP/UDP communication)
  3. DNS lookups
  4. Timers (setTimeout(), setInterval())
  5. Thread pool tasks (such as file I/O, cryptographic operations, and compression)

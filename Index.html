Part 1: Theory Questions

Node.js Basics

1. What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser. It is built on Google's V8 JavaScript Engine and is mainly used for building fast, scalable, and server-side applications.

2. What is the difference between Single-threaded and Multi-threaded architecture?

Single-threaded

-Uses only one thread to execute tasks.

-Executes one task at a time.

-Uses an event loop for handling asynchronous operations.

-Example: Node.js

Multi-threaded

*Uses multiple threads to execute tasks simultaneously.

*Executes multiple tasks at the same time.

*Different threads can handle different tasks independently.

*Example: Java, C#

3. What is the difference between Synchronous and Asynchronous operations?

Synchronous Operations

-Tasks are executed one after another.

-The next task waits until the current task finishes.

-It is blocking in nature.

Asynchronous Operations

-Tasks do not wait for previous tasks to finish.

-Other operations continue while waiting.

-It is non-blocking in nature.

4. What is the difference between Blocking and Non-blocking operations?

Blocking

-Stops the execution until the task is completed.

-Other code must wait.

-Usually synchronous.

Non-blocking

-Does not stop the execution.

-Other code continues to run.

-Usually asynchronous.

Modules

5. What is a Module in Node.js?

-A module is a reusable piece of code that contains functions, variables, or objects. Modules help organize code and make applications easier to maintain.

6. What is the purpose of module.exports?

-module.exports is used to export functions, objects, or variables from one file so they can be used in another file.

7. What is the purpose of require()?

-require() is used to import modules into another file so their exported functions or objects can be used.

NPM

8. What is NPM?

NPM (Node Package Manager) is the default package manager for Node.js. It is used to install, manage, update, and remove packages (libraries) in a Node.js project.

9. What information is stored inside the package.json file?

- Project name

- Version

- Description

- Main entry file

- Scripts

- Author

- License

- Dependencies

- DevDependencies

Core Modules

10. What is the purpose of the HTTP Module?

The HTTP module is used to create web servers and handle HTTP requests and responses.

11. What is the purpose of the URL Module?

The URL module is used to parse, create, and manipulate URLs. It helps extract information such as pathname, hostname, query parameters, and protocol.

12. What is the purpose of the File System (fs) Module?

The File System (fs) module is used to work with files and directories. It allows developers to create, read, write, update, rename, and delete files.

13. What is the purpose of the Path Module?

The Path module is used to work with file and directory paths. It helps create, join, normalize, and resolve file paths across different operating systems.

14. What is the purpose of the Events Module?

The Events module is used to create and handle custom events in Node.js. It allows different parts of an application to communicate using an event-driven approach.
